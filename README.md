# Adventures of Pingo — Demo

Demo gratuita de **Adventures of Pingo** (até a 2ª insígnia): https://jaapa07.github.io/Pingo-demo1/

No celular, abra o link e use "Adicionar à Tela de Início" (iPhone/Safari) ou "Instalar app" (Android/Chrome) para jogar como app, até sem internet.

Este repositório contém apenas o jogo já montado (gerado por `npm run build:demo`).
